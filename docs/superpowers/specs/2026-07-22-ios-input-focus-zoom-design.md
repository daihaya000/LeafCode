## 背景

iPhone Safari は、フォーカスする `input`、`textarea`、`select` の実効フォントサイズが16px未満の場合、読みやすさを確保するためページを自動拡大する。現在は各コンポーネントが `text-xs`、`text-sm`、任意サイズを個別に指定しており、入力欄の一部がこの条件に該当する。

## 目的

iPhoneで入力欄へフォーカスしてもページが自動拡大しないよう、すべての通常のフォーム入力要素の実効フォントサイズを16px以上に統一する。

## 対象と非対象

- 対象: `web/src/app/globals.css` における `input`、`textarea`、`select` の共通フォントサイズ。
- 対象: 既存・将来のフォーム入力要素への一貫したSafari対策。
- 非対象: viewportのズーム制限、`user-scalable=no`、`maximum-scale` の追加。
- 非対象: 入力要素以外の文字サイズ、レイアウト、色、操作フローの変更。

## 設計

`globals.css` に以下の共通ルールを追加する。

```css
input,
textarea,
select {
  font-size: 16px;
}
```

- 共通ルールは、コンポーネントごとの小さい文字サイズ指定より優先して、フォーム要素の実効サイズを16pxへ統一する。
- ページ全体のピンチズームは抑制しない。iOSのアクセシビリティとユーザー操作を維持する。
- CSSのみの変更とし、コンポーネントのDOM・状態・イベント処理は変更しない。

## 受け入れ条件

1. iPhone Safariで表示中の `input`、`textarea`、`select` にフォーカスしても、ページが自動拡大しない。
2. ピンチズームなど、ユーザーが明示的に行う拡大操作は制限されない。
3. 既存のフォーム入力、選択、送信操作は変更されない。
4. CSS構文と既存のWebアプリ型チェックが通る。

## 検証

- `cd web && npx tsc --noEmit`
- iPhone実機またはiOS Safariで、ホーム、タスク詳細、設定、コマンドパレットの入力欄をフォーカスして自動拡大しないことを手動確認する。
