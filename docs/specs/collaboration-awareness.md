# 並行セッション相互認識

> 実装ステータス: ✅ 実装済み（参照: `web/src/lib/collaboration-context.ts` / `collaboration-context.test.ts`）

## 目的

同じワークスペースで同時に動くセッションへ、他セッションの存在と編集対象を伝え、意図しない上書きや巻き戻しを減らす。

## 動作

- WebUIからユーザープロンプトを送る直前に、同じワークスペースのOpenCodeセッション状態を取得する。
- `busy` または `retry` の他セッションを最大5件取得する。
- 各セッションのタイトルと、edit/write/patch系ツールで触れたファイルを最大8件収集する。
- 情報を `<collaboration-context>` としてプロンプトの先頭へ付加する。
- コンテキストには、他セッションの変更を上書き・巻き戻しせず、重複をユーザーへ報告するよう明記する。
- この内部ブロックはトランスクリプトには保存されるが、WebUIの会話表示からは除外する。

## 介入方針

- 通知して継続する。ファイルロック、セッション停止、確認ダイアログは行わない。
- 状態取得やトランスクリプト取得に失敗しても、本来のプロンプト送信は止めない。
- 生成中のターンへ途中からメッセージを割り込ませない。相互認識スナップショットは各ターンの送信直前に更新する。
- ワークスペースとディレクトリの対応が一意でない場合は注入しない。別ワークスペースの情報を混在させない。
